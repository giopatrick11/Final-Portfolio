# Gio Patrick Cimeni — Portfolio

A responsive portfolio for a full-stack developer, built with React, Vite, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

Portfolio content lives in `src/data/portfolio.js`. Reusable page components are in `src/components`, while the main page composition is in `src/pages/Home.jsx`.
